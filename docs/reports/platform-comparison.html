Ume LLM Gateway compared with eneo

Both platforms ran on the same hardware against the same simulated AI model, which answers instantly. Everything measured is the platforms' own work.

On the same hardware the gateway handles about 200 times as many messages, adds 46 times less delay to each one and keeps working when overloaded. It also checks every message for personal data and switches to another AI provider when one fails; eneo does neither.

Personal data

The gateway stops personal data before it reaches the AI model; eneo passes it on

We sent the same message to both, with a personal identity number (Skatteverket's public test number), an e-mail address and a phone number. This is exactly what the AI model received.

eneo v2.2.1 sent unchanged, and saved in its chat history

The policy is chosen per key. Detection looks for identity and co-ordination numbers (with checksum), e-mail addresses, phone numbers and bank account numbers (IBAN); it does not recognise names or free-text health information.

Reading the results fairly

Different kinds of product, measured on the same task

What eneo does extra

eneo is a full chat application: it stores every conversation, resolves assistants, spaces and permissions, and counts tokens for each message. The gateway passes requests on to the AI model and records usage, which is its whole job.

What it means in practice

For one user the difference is hidden behind the AI model's own answer time. For many users it decides how much hardware is needed and whether the service stays up at peak load.

The gateway's own limit

One gateway instance currently tops out at about 11 000 messages per second, limited by how fast it saves usage records. That is far above expected load; an improvement is planned, and more instances can be added.

How it was measured

Same machine (8-core AMD Ryzen 7 9800X3D), same simulated AI model, each platform given the same processor cores; eneo v2.2.1 built from its official release. Each figure is 20–30 seconds of steady load, and every answer was checked. Scripts: benchmarks/compare.
